# LED-countdown
I use an LED and passive buzzer to create a countdown timer. The user enters their desired time in seconds, then the time is split into 5 intervals(one for each LED), at the ned their is an alarm.

**Componenst used:**
 - 5 LED's
 - 5 Resistors
 - passive buzzer
 - jumper wires
